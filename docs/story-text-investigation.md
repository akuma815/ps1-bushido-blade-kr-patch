# 스토리·시스템 문자열 조사

## 목표

그래픽 PoC와 별개로 스토리 대사와 시스템 문구가 다음 중 어느 경로인지
판정한다.

- 디스크의 일반 문자열
- 사용자 정의 인코딩 문자열
- TIM 또는 다른 그래픽에 베이크된 텍스트
- STR 영상에 포함된 텍스트
- 음성만 있고 화면 문구가 없는 장면

## BBJ-TEXT-SJIS-001 정적 감사

일본판 원본의 2MB 이하 Form 1 파일을 Shift-JIS로 넓게 스캔했다.

| 항목 | 결과 |
| --- | ---: |
| 후보가 나온 파일 | 327 |
| 넓은 후보 run | 581,241 |
| 히라가나 3자 이상, 100자 이하 | 8 |
| 확인된 게임 대사 | 0 |

좁힌 8건은 바이너리 오검출 4건, 효과음 이름 `セミしぐれ(16)` 1건,
Macintosh 메타데이터 오류 문구 3건이다. 이전 화면 원문 6종의 정확한
Shift-JIS 검색에서도 `対戦モード`가 들어간 메모리카드 제목 한 건만
발견됐다.

판정은 **불명확**이다. 평문 Shift-JIS 대사의 근거는 없지만, 이 결과만으로
사용자 정의 인코딩·압축·그래픽·영상·음성 경로를 제외하지 않는다.
기계 요약은 `work/analysis/sjis_audit_round1_summary.json`이 소유한다.

## BBJ-HITL-TEXT-001

- 기준선: 일본판 `SLPM-86020`, DuckStation 0.1.11621
- 시작 상태: 원본 CUE 부팅 후 메인 메뉴
- 절차:
  1. 스토리 모드에 진입한다.
  2. 첫 일본어 화면 문구 직전에 `F2`로 세이브한다.
  3. 문구가 완전히 표시된 프레임에서 `F10`을 누른다.
  4. 문구가 바뀌면 화면마다 `F10`을 추가한다.
- 응답: `캡처 완료: 스토리 1차`
- 분기:
  - 화면 문구 있음: 원문을 전사하고 디스크 파일·TIM·STR과 대조한다.
  - 화면 문구 없음: 음성 전용 가능성을 기록하고 시스템 UI 표본으로
    문자열 경로 조사를 이동한다.
  - 영상에만 문구 있음: STR 프레임 자막 경로를 별도 그래픽 트랙으로 연다.

후속 표본은 전투 일시정지, 승패 결과, 저장·불러오기 순서로 수집한다.

## BBJ-HITL-TEXT-001 결과

- 사용자 관찰: 완료한 한 스토리 루트의 진행 중 대사는 전부 음성으로만
  재생됐고 화면 자막은 없었다.
- 전투 중 일시정지에도 화면 텍스트가 없었다.
- 확인한 스토리 모드의 승패 결과에도 화면 텍스트가 없었다.
- 게임 메뉴에는 저장·불러오기 항목이 없었다. 자동 저장이나 다른 시점의
  메모리카드 접근 여부는 이 관찰만으로 판정하지 않는다.
- 화면 일본어는 루트 마지막의 세로 엔딩 문구에서 확인됐다.
- 이 결과는 관찰한 루트에 한정한다. 다른 캐릭터와 분기를 조사하기 전에는
  게임 전체가 동일하다고 단정하지 않는다.

따라서 본편 음성 대사는 기존 문자열을 번역·재삽입하는 작업으로 처리할 수
없다. 전체 대사 한글화를 범위에 넣으려면 음성 유지 + 신규 자막 오버레이,
또는 한국어 음성 교체 중 하나를 별도 고난도 트랙으로 열어야 한다.

일시정지·스토리 승패·저장/불러오기 메뉴에서 조사할 동적 문자열 표적도
확보되지 않았다. 일반 문자열 경로 조사는 새 화면 증거가 나올 때까지
보류하고, 다음 주 작업을 베이크된 TIM 그래픽 전수 분류로 이동한다.

런타임 캡처
`work/screenshots/story_round1/ブシドーブレード 2026-07-29-22-11-40.png`를
TIM 전수 추출물과 대조했다.

| 항목 | 판정 |
| --- | --- |
| 세로 본문 | `DATA3/O15.DAT @ 0x3388`, 64x216, 4bpp TIM |
| 서명 `神和斎` | `DATA3/O15.DAT @ 0x6888`, 24x40, 4bpp TIM |
| 원본 `O15.DAT` SHA-256 | `486D464AB79F2FBB1E783DB7A00ACC8496AB5B3E979D52F037BE9F735FD27E90` |
| Shift-JIS 정확 검색 | `修羅の道`, `修羅` 모두 0건 |

캡처와 두 TIM의 글자 배열이 정확히 일치하므로 이 엔딩 화면은 동적 문자열이
아니라 베이크된 세로 문구와 서명을 합성한다. 같은 파일에 든 세로 문구 5개와
서명 1개의 편집용 PNG를 `workspace/graphics/ending/source`에 분리했다.
정확 검색 결과는 `work/analysis/story_ending_exact_sjis.json`에 보존했다.

다음 엔딩 PoC에서는 원본 TIM의 크기·팔레트·투명색을 유지한 채 `0x3388`과
`0x6888` 중 필요한 자산만 교체하고, 같은 루트를 다시 완료하거나 직전
세이브스테이트에서 재진입해 합성 위치와 회귀를 확인한다.
