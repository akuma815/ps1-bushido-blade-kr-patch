# 공개 소스 안내

분석·추출·재삽입·빌드 스크립트, 번역 원장(XLSX/CSV/JSON), 설정과 작업 문서를 원래 상대 경로로 보존했습니다. 이 저장소는 2026-10-16 작업 폴더에서 선별한 소스 스냅샷입니다.

원본·BIOS·추출 바이너리·이미지·영상·세이브·QA 덤프·캐시·외부 실행 파일은 Git 추적에서 제외했습니다. 원본 기반 그래픽과 미디어를 입력으로 쓰는 빌드는 사용자가 보유한 원본에서 해당 자산을 다시 추출해야 합니다. 원본 경로, 폰트, 외부 도구 및 프로젝트 간 상대 경로 의존성은 기존 스크립트와 문서를 확인하세요. 저장소만 복제해 모든 빌드를 실행할 수 있다는 검증은 하지 않았습니다.

번역 원장은 그대로 보존했으며 번역문·행 상태를 일괄 수정하지 않았습니다. 소스 스냅샷과 기존 최종 배포본의 빌드 시점은 다를 수 있으며, 배포 파일은 README와 릴리즈에 고정한 기존 최종본입니다.

## 검증 범위

이번 공개 준비에서는 파일 목록·SHA-256·인증정보 패턴·ZIP CRC와 원본 게임 파일 포함 여부를 검사했습니다. 새로운 게임 빌드, 패치 적용, 에뮬레이터 실행 또는 전체 플레이 검수는 수행하지 않았습니다. 과거 검증 결과는 배포 안내와 원래 작업 기록의 해당 버전·범위에 한정됩니다. 기존 문서의 로컬 산출물·QA 링크는 공개 저장소에 포함되지 않을 수 있습니다.

게임과 외부 도구·폰트의 저작권 및 라이선스는 원 권리자의 조건을 따릅니다. 배포 ZIP의 도구·라이선스·소스 제공 파일을 함께 보존했습니다.
