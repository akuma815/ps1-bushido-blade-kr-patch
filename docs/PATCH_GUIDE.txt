원본 또는 패치 완료 디스크 이미지는 배포물에 포함되지 않습니다.

두 패치는 서로 독립적입니다. 원하는 쪽만 적용하면 되고, 둘 다 적용해도
됩니다. 하나의 디스크에 두 판을 합칠 수는 없습니다.


■ 1. 적용 방법

원본 BIN 파일을 해당 cmd 파일 위로 끌어다 놓거나 다음처럼 실행합니다.

  apply_usa.cmd "Bushido Blade (USA).bin"
  apply_jp.cmd  "Bushido Blade (Japan).bin"

출력은 원본 옆의 `<원본 이름>_KR.bin`이며, 짝이 되는 `_KR.cue`도 함께
만들어집니다. 에뮬레이터에는 **cue 파일**을 여는 것을 권장합니다.

커지는 것은 정상입니다(한글 자막 데이터를 이미지 끝에 덧붙였습니다).


■ 2. 두 판의 공통점

  · 타이틀 로고가 한글 `무사도의 검`으로 교체됩니다.
  · 캐릭터 선택 화면의 인물 이름이 한글로 나옵니다.
  · 승리 시 대사가 한글 자막으로 나옵니다.
  · 영상 갤러리가 처음부터 전부 열려 있습니다.
  · 게임 진행에 필요한 조작·시스템 표기 대부분이 한글입니다.

두 판 모두 음성은 일본어 원음 그대로이며, 자막만 추가·교체했습니다.


■ 3. 두 판의 차이점 — 어느 쪽을 고를까

두 판은 자막 엔진이 서로 다릅니다. 그래서 번역 범위가 갈립니다.

  ┌──────────────────────────┬────────────┬────────────┐
  │ 항목                     │  미국판    │  일본판    │
  ├──────────────────────────┼────────────┼────────────┤
  │ 도입부 컷신 자막         │     O      │     X      │
  │ 전투 전 상대 대사        │     O      │     X      │
  │ 승리 시 대사             │     O      │     O      │
  │ 엔딩 자막                │     O      │     X      │
  │ 배드엔딩 문구 이미지     │     O      │     O      │
  │ 무비 갤러리 전체 해금    │     O      │     O      │
  ├──────────────────────────┼────────────┼────────────┤
  │ 타이틀 로고              │     O      │     O      │
  │ 로딩 로고                │     O      │     O      │
  │ 캐릭터 선택 이름         │     O      │     O      │
  │ 메인 메뉴 · 옵션 화면    │     X      │     O      │
  │ 캐릭터 프로필 화면       │     X      │     O      │
  │ 무기 선택 · 대전 설정    │     X      │     O      │
  └──────────────────────────┴────────────┴────────────┘

  ▶ 스토리를 이해하며 즐기고 싶다면 → **미국판**

    미국판은 원래부터 게임 내부에 자막 표시 기능을 갖추고 있어, 컷신과
    엔딩을 포함한 모든 대사를 한글로 옮길 수 있었습니다.

  ▶ 메뉴와 UI를 한글로 보고 싶다면 → **일본판**

    일본판은 메뉴·옵션·프로필 같은 화면 텍스트가 이미지로 되어 있어
    통째로 한글화했습니다. 대신 컷신과 엔딩에는 자막을 넣을 수 없었습니다.
    (일본판 엔진은 영상 재생 중 자막을 그리는 경로 자체가 없습니다.)

  한 판에 양쪽을 모두 넣는 것은 불가능합니다. 두 판은 텍스트를 다루는
  방식이 근본적으로 달라, 서로의 자산을 옮겨 붙일 수 없습니다.


■ 4. 실행 환경

권장 에뮬레이터는 DuckStation입니다. cue 파일을 열어 실행하세요.
한글 자산은 모두 디스크 이미지에 내장되어 있어 별도 폰트나 텍스처 팩은
필요하지 않습니다.


■ 4-1. 영상 갤러리

두 판 모두 타이틀 화면의 영상 감상 메뉴가 처음부터 전부 열려 있습니다.
스토리를 끝내지 않아도 모든 엔딩 영상을 바로 볼 수 있습니다.

해금 상태만 강제했을 뿐 세이브 데이터에는 손대지 않으므로, 기존 세이브를
그대로 써도 되고 패치를 지워도 세이브가 망가지지 않습니다.


■ 5. 알려진 제약

  · 음성은 일본어 원음입니다.
  · 일본판은 컷신·엔딩 자막이 없습니다(위 3항 참고).
  · 미국판은 메뉴·옵션 등 UI 이미지가 영문 그대로입니다.
  · 두 판 모두 캐릭터 선택 화면 아래쪽 세로 간판(한자)은 원본 그대로
    두었습니다. 배경 장식 요소로 판단했습니다.


■ 6. 제거

원본 BIN/CUE를 그대로 다시 사용하면 됩니다. 패치는 원본을 수정하지 않고
별도 파일을 만듭니다.


■ 7. 주의

패치 적용이 끝난 BIN 파일을 배포하지 마세요. xdelta 파일만 공유할 수
있습니다. SHA256.txt로 다운로드한 배포 파일의 무결성을 확인할 수 있습니다.
