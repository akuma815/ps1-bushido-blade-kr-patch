# 원본 화면 카탈로그 캡처 가이드

사용자가 표를 직접 작성할 필요는 없다. DuckStation에서 원본 화면을
캡처하면 캡처 파일의 분류, 원문 전사, 텍스트 블록 분할, 자산 후보 연결은
프로젝트 기록에서 처리한다.

## 캡처 방법

1. DuckStation에서 일본판을 플레이한다.
2. 일본어 문구가 나타난 화면에서 `F10`을 한 번 누른다.
3. 선택 항목을 옮겼을 때 글자·색·배경이 달라지면 선택 전후를 각각 찍는다.
4. 같은 화면에서 문구만 바뀌면 문구가 바뀔 때마다 한 장씩 찍는다.
5. 접근하기 어려운 화면에서는 `F2`로 세이브스테이트도 저장한다.
6. 파일을 자르거나 이름을 바꾸지 않는다. 원본 PNG를 그대로 둔다.
7. 한 모드를 마치면 채팅에 `캡처 완료: <모드명>`이라고 알려 준다.

DuckStation 기본 단축키:

- `F10`: 스크린샷
- `F2`: 현재 슬롯 세이브
- `F1`: 현재 슬롯 로드
- `F3` / `F4`: 세이브 슬롯 변경
- `Space`: 일시정지
- `F11`: 전체 화면 전환

## 첫 캡처 범위

첫 라운드에서는 아래 화면만 확보한다.

1. 제작사·퍼블리셔 로고
2. 타이틀 화면
3. 메인 메뉴
4. 옵션
5. 캐릭터 선택
6. 무기 선택
7. 대전 시작 전 화면
8. 전투 중 UI
9. 일시정지
10. 승패·결과 화면
11. 스토리 모드 첫 연출
12. 스토리 모드 첫 일본어 문구
13. 저장·불러오기 화면

엔딩·크레디트와 숨은 모드는 첫 PoC 이후 두 번째 라운드에서 수집한다.

## 좋은 캡처의 기준

- 화면 전체가 포함돼야 한다.
- DuckStation 메뉴나 다른 창이 게임 화면을 가리지 않아야 한다.
- 문구가 페이드 중이 아니라 완전히 표시된 프레임을 우선한다.
- 애니메이션 때문에 읽기 어려우면 `Space`로 멈춘 뒤 `F10`을 누른다.
- 같은 문구의 중복 캡처는 문제없다. 누락보다 중복이 낫다.
