# 배경 글자 후보

`source`는 일본판 원본에서 추출한 정본이며 수정하지 않는다.
`edited`는 이후 시험용 복사본이다.

이 폴더의 후보는 간판, 벽보, 낙서처럼 글자와 배경이 한 장에 합쳐진
보호 그래픽이다. 런타임에 실제로 쓰이는 위치와 텍스트 영역 마스크를
확정하기 전에는 한글 편집본을 게임에 삽입하지 않는다. 저해상도 변형은
같은 표지의 밉맵 또는 거리별 텍스처일 수 있으므로 함께 보존한다.

기계 판독 목록은 `candidate_catalog.json`, 선정 근거는
`../catalog/environment_text_selection.json`에 있다.
