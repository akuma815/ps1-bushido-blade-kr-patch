# DATA3 일본어 그래픽 후보

- `source`: 일본판에서 추출한 보존 원본 125개
- `edited`: 편집용 복사본 125개
- `candidate_catalog.json`: 경로·TIM 오프셋·크기·픽셀 해시

이 폴더는 DATA3 1차 시각 검토 결과이며 아직 확정 번역 분모가 아니다.
`source`는 수정하지 않는다. `edited`는 같은 이름을 유지하고 캔버스 크기를
바꾸지 않는다.

`DATA3_O19_DAT_0000010C.png`는 인물·배경과 일본어가 합쳐진 통이미지이므로
전체 이미지를 덮지 않는다. 텍스트 바운딩 박스와 보호 마스크가 정해질 때까지
편집을 보류한다.

후보 내보내기를 다시 실행해도 기존 `edited` 파일은 덮어쓰지 않는다.
